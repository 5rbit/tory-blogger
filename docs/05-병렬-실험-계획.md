# 05. 병렬 실험 계획 — 타겟별 블로그를 동시에 굴려 승자를 고른다

## 1. 원칙

- 하나의 주제에 올인하지 않는다. **타겟이 다른 블로그 4개**를 같은 파이프라인으로 동시에 운영하고, 12주 데이터로 집중 대상을 고른다
- 수익원은 세 가지로 통일한다: **애드포스트(타겟별 단가 차이 측정) · 네이버 메이트(AI 브리핑 인용) · 쇼핑커넥트(상품 링크 1개/글)**. 체험단·CPA는 부차 지표
- 모든 실험은 같은 글 규칙을 따른다: 서두 한줄요약(메이트 인용용), 실측 표 1개, 사진 5장, 상품 슬롯 1개, 경험 문장 3개
- 네이버 아이디 1개 = 블로그 1개. 실험 4개 = 아이디 4개 (1인 최대 3개 + 가족 명의 1개, 또는 3개로 시작)

## 2. 실험 목록

| ID | 타겟 | 주제 | 가설 | 월 비용 |
|----|------|------|------|---------|
| `it-gear` | 재택·개발자·사무직 20~40대 남성 | IT·가전 제품 구매 가이드 | 구매 직전 키워드 + 실측은 쇼핑커넥트 전환과 IT 광고 단가가 최고 | 20만 |
| `finance` | 사회초년생·30대 직장인 | 재테크·금융 상품 비교 | 금융 애드포스트 단가가 최고. 초보 블로그로 노출되는지 검증 | 0 |
| `health` | 30~50대 직장인 | 건강 관리·영양제 비교 | 검색 수요 최대. 건기식 쇼핑커넥트 전환과 저품질 여부 검증 | 10만 |
| `travel` | 수도권 20~30대 커플·가족 | 근교 당일·1박 여행 | 트래픽 총량으로 애드포스트, 코스 글이 메이트에 인용되는지 검증 | 30만 |

각 실험 설정은 `experiments/<id>/pipeline.yaml` 에 있고, base 설정(`config/pipeline.yaml`) 위에 덮어쓴다. 데이터는 `data/<id>/` 로 분리된다.

## 3. 실행 방법

```bash
# 모든 실험의 주간 계획 (월요일)
python scripts/weekly_plan.py --all
# 실험별 초안 (매일)
python scripts/daily_draft.py --all
# 특정 실험만
python scripts/daily_draft.py --exp it-gear
# 발행 (블로그별 브라우저 프로필 자동 분리)
python scripts/fill_editor.py --exp it-gear data/it-gear/drafts/2026....md
# 실험 비교표
python scripts/compare.py
```

사람 시간: 실험 4개 × 하루 1편이면 발행 클릭·사진만 하루 40분. 부담되면 실험당 주 3편으로 줄인다 (`schedule.posts_per_week`).

## 4. 측정 지표 (실험 간 동일)

| 지표 | 수집 | 판단 기준 |
|------|------|-----------|
| 일 방문자 | 블로그 통계 CSV (주 1회) | 4주 50 / 8주 200 / 12주 500 |
| 검색 유입 비율 | 통계 CSV | 12주 40% 이상 |
| 상위 5위 노출 키워드 수 | 검색 API로 자동 확인 (구현 예정) | 12주 10개 |
| 방문자당 애드포스트 수익 (RPM) | 애드포스트 리포트 | **타겟별 단가 비교의 핵심** |
| AI 브리핑 인용 횟수 | 수동 확인 → 메이트 신청 | 8주부터 |
| 쇼핑커넥트 클릭·전환 | 브랜드커넥트 리포트 | 12주 전환 1건 이상 |
| 방문자당 총수익 ÷ 월 비용 | compare.py | **최종 승자 기준** |

## 5. 중단·집중 규칙

- **4주**: 검색 유입이 0에 가깝거나 누락(저품질) 징후가 있는 실험은 원인 점검. 글 규칙 위반이면 수정, 주제 문제면 대기
- **8주**: 방문자 하위 2개 실험은 주 5편 → 주 2편으로 감량
- **12주**: 방문자당 총수익이 가장 높은 실험 1~2개에 집중. 나머지는 유지 모드(주 1편) 또는 종료
- 예외: `finance` 는 단가가 높아 방문자가 적어도 수익이 나올 수 있으므로 RPM 으로 따로 본다

## 6. 리스크

| 리스크 | 대응 |
|--------|------|
| 같은 IP·기기에서 여러 블로그 운영 → 어뷰징 의심 | 발행은 사람이 각각, 브라우저 프로필 분리, 하루 1편/블로그. 동일 글 복제 금지 |
| 4개 동시 운영으로 사진·경험 준비 부족 | 주말 일괄 촬영, 부담 시 실험당 주 3편 |
| 건강·금융의 규제 표현 | 금칙어 목록을 실험별 review 설정에 추가 (예정) |
