# 05. 실험 계획 — 한 페르소나 안에서 무엇이 돈이 되는지 검증

블로그는 하나(`hiker`)다. 대신 **글 유형과 지역을 변수**로 두고 12주간 같은 조건에서 비교한다.

## 1. 실험 변수

| 변수 | 수준 | 측정 |
|------|------|------|
| 글 유형 | 코스형 / 계절 큐레이션형 / 용품 리뷰형 | 유형별 방문자, 쇼핑커넥트 클릭·전환, 체류 시간 |
| 지역 | 수도권 근교(당일) / 지방 명산(1박) | 검색 유입, 맛집 섹션 클릭 |
| 용품 배치 | 본문 중간 경험담 / 하단 "오늘 챙긴 것" | 링크 클릭률 |
| 발행 시점 | 검색 피크 3주 전 / 1주 전 | 상위 노출 도달 여부, 피크 주 방문자 |

초안 파일 이름과 키워드 YAML 의 `post_type`, `extra.region`, `extra.gear_position` 으로 기록해 `compare.py` 가 유형별로 집계한다.

## 2. 판단 시점

- 4주: 검색 유입 0에 가까운 유형이 있으면 글 구조 점검
- 8주: 쇼핑커넥트 클릭률이 가장 높은 용품 배치로 통일
- 12주: 방문자당 수익이 높은 유형·지역 비율을 60% 이상으로 조정

## 3. 두 번째 블로그

같은 아이디로는 블로그가 하나이므로, 12주 후 데이터가 좋으면 **지역 특화 2호**(예: 제주·설악 전문) 를 별도 아이디로 연다. `experiments/` 구조는 그대로 쓴다.
