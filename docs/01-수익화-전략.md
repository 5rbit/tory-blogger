# 01. 수익화 전략 — "산 다니며 일하는 등산 블로거"

## 0. 페르소나

- 주 2~3회 산에 가는 등산 애호가. 등산 다니면서 디지털 노마드로 사는 블로거
- 글의 축: **이맘때 가기 좋은 코스** + **직접 찍은 사진** + **네이버 지도 루트** + **입고 간 용품** + **하산 후 맛집**
- 독자에게 주는 가치: "이번 주말 어디 갈까"에 대한 답을 코스·교통·용품·밥까지 한 번에

## 1. 목표

- 6개월: 일 방문자 1,500, 애드포스트 승인, 쇼핑커넥트 월 전환 5건, 월 수익 50만 원
- 12개월: 일 방문자 4,000, 인플루언서(여행·아웃도어) 선정, 네이버 메이트, 월 수익 200만 원
- 운영 시간: 산행 외 주 3시간

## 2. 왜 등산인가 (돈의 관점)

| 항목 | 근거 |
|------|------|
| 검색량 | 계절성이 강하고 반복된다. "OO산 단풍 시기", "OO산 등산코스" 는 매년 같은 달 검색이 급증한다 → **작년 데이터로 올해 글 시점을 예측**할 수 있다 |
| 커머스 | 등산화·배낭·스틱·의류는 객단가 5~30만 원, 쇼핑커넥트 수수료가 붙는 상품군. "코스 소개 + 그날 신은 등산화" 는 광고 티가 안 난다 |
| 협찬 | 아웃도어 브랜드 체험단이 상시 있고 건당 5~10만 원 |
| 메이트(AI 브리핑) | 코스 거리·시간·난이도 표, 들머리 주차, 직접 찍은 사진은 AI가 만들 수 없는 1차 정보 → 인용 대상 |
| 지역 맛집 | 하산 후 맛집은 지역 검색 트래픽을 추가로 가져오고 체험단 수요도 있다 |
| 경쟁 | 등산 블로그는 많지만 "이맘때 + 루트 + 용품 + 맛집" 을 구조화한 글은 드물다 |

## 3. 수익원과 착수 순서

| 순위 | 수익원 | 방법 | 착수 |
|------|--------|------|------|
| 1 | **쇼핑커넥트** | 글마다 그날 실제로 쓴 용품 1개 링크 (등산화·스틱·배낭·재킷·양말·보온병) | 첫 글부터 |
| 2 | **애드포스트** | 계절 키워드 트래픽. 아웃도어·여행은 단가 중간이지만 총량이 크다 | 글 50편 |
| 3 | **네이버 메이트** | 코스 표·주차·교통·소요시간 등 인용되는 1차 정보 | 3개월 |
| 4 | **체험단·협찬** | 아웃도어 브랜드, 등산 앱, 지역 숙소·맛집 | 3주차 플랫폼 가입 |
| 5 | **인플루언서 (여행 또는 스포츠·아웃도어)** | 팬 확보 후 프리미엄 광고·브랜드커넥트 | 6개월 |
| 6 | 디지털 상품 | "계절별 100대 명산 코스북" PDF, 초보 장비 체크리스트 | 6개월 이후 |

쿠팡 파트너스는 쓰지 않는다. 같은 3%대 수수료에 저품질 위험만 있다. 네이버 자체 쇼핑커넥트로 통일한다.

## 4. 글의 표준 구조 (모든 코스 글 공통)

1. **한줄요약** — 이 코스를 언제, 누가, 왜 가면 좋은지 2~3문장 (메이트 인용용)
2. **코스 요약 표** — 들머리·날머리, 거리, 소요시간, 난이도, 고도, 화장실·주차 (공공데이터 + 실측)
3. **이맘때 포인트** — 단풍·야생화·눈꽃·조망 등 시기 근거. 작년 사진과 비교
4. **구간별 설명** — 직접 찍은 사진 5장 이상, 구간별 소요시간 실측
5. **네이버 지도 루트** — 들머리 길찾기 링크 + 경로 캡처 (iframe 불가, 링크만)
6. **오늘 챙긴 것** — 그날 실제 사용한 용품 1개를 경험담으로. `[상품: ...]` 슬롯 → 쇼핑커넥트
7. **하산 후 밥** — 들머리 반경 3km 맛집 3곳 (지역 검색 API + 직접 간 곳 1곳 표시)
8. **주의사항·교통** — 대중교통, 주차, 입산 통제, 일몰
9. 해시태그 7개

## 5. 콘텐츠 유형과 비율

| 유형 | 비율 | 예시 |
|------|------|------|
| **코스형** | 60% | "10월 둘째 주 설악산 흘림골 단풍 코스 (실측 4시간 20분)" |
| **계절 큐레이션형** | 20% | "이번 주말 수도권 단풍 산 5곳 (거리·시간 표)" — 내부 링크 허브 |
| **용품 리뷰형** | 15% | "6개월 400km 신은 등산화 솔직 후기 (밑창 사진)" |
| **디지털 노마드형** | 5% | "산 아래 카페에서 일하는 하루" — 페르소나·팬 확보용 |

발행 빈도: 주 3편 (산행 2~3회에 맞춤). 산행 없는 주는 큐레이션형·용품형으로 채운다.

## 6. "이맘때" 를 찾는 방법 (자동화)

1. 데이터랩 검색어 트렌드 API로 "OO산 단풍", "OO산 등산코스" 의 **월별 검색 비율 시계열**을 받는다 (최근 3년)
2. 매년 피크가 오는 주를 찾아 **피크 3주 전**에 발행 캘린더에 올린다
3. 검색광고 API로 그 주의 키워드 월 검색량·경쟁도를 붙여 돈 점수를 매긴다
4. 전국등산로표준데이터(공공데이터포털)에서 해당 산의 코스·거리·시간·난이도를 받아 표 초안을 만든다

## 7. 사진 원칙

- **본인이 찍은 사진만** 쓴다. 타인의 리뷰 사진은 AI로 구도를 바꿔도 저작권 침해이고 네이버 유사 이미지 판정 대상이다
- 본인 사진은 AI 도구로 구도 보정·색감·크롭·계절감 강조를 해도 된다. 단, 실제와 다른 풍경을 만들지 않는다 (신뢰가 자산)
- 같은 코스를 여러 계절 찍어 "작년 이맘때 vs 올해" 비교 사진을 만든다. 이것이 경쟁자가 못 따라오는 자산이다

## 8. 하지 말아야 할 것

- 가보지 않은 코스를 공공데이터만으로 쓰는 것 → D.I.A. 감점, 신뢰 붕괴. 큐레이션형에서는 "가본 곳" 표시로 구분
- 글당 상품 링크 2개 이상, 용품 글 비율 30% 초과 → 상업성 판정
- 하루 2편 이상 발행, 완전 자동 발행
- 맛집을 가보지도 않고 추천처럼 쓰는 것 → "근처 식당 목록" 과 "직접 간 곳" 을 구분해 표기
