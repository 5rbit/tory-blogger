# 03. 12주 로드맵 및 KPI

## 1. 로드맵

| 주차 | 목표 | 산출물 | 사람 작업 |
|------|------|--------|-----------|
| 1–2 | 기반 | 문서 확정, 파이프라인 골격, 검색광고 API 연동, 키워드 100개 발굴 | 블로그 주제·프로필·카테고리 정비, 네이버 API 키 발급 |
| 3–4 | 발행 시작 | 코스형 글 주 3편, 지역 검색으로 맛집 표 자동 | 산행마다 사진 20장, 발행, 이웃 10명/일 |
| 5–8 | 단풍 시즌 | 큐레이션 허브 글, 용품 리뷰 시작, fill_editor 완성 | 아웃도어 체험단 신청, 쇼핑커넥트 링크 전환 확인 |
| 9–12 | 겨울 준비 | 눈꽃·설산 캘린더, 유형별 수익 비교로 비율 조정 | 애드포스트 신청(글 50편), 메이트 지원 |

## 2. KPI

| 지표 | 4주 | 12주 | 6개월 | 12개월 |
|------|-----|------|-------|--------|
| 누적 발행 수 | 20 | 60 | 120 | 250 |
| 일 방문자 | 50 | 400 | 1,500 | 4,000 |
| 검색 유입 비율 | 20% | 40% | 50% | 60% |
| 상위 5위 노출 키워드 | 3 | 15 | 40 | 100 |
| 애드포스트 | - | 신청 | 승인, 월 20만 | 월 50만 |
| 인플루언서 | - | - | 신청 | 선정 |
| 체험단·협찬 | - | 2건 | 월 3건 | 월 5건 + 원고료 |
| 사람 개입 시간 | 주 4h | 주 3h | 주 3h | 주 2h |

## 3. 주간 점검 항목 (weekly_report 출력)

1. 발행 수 대비 계획 달성률
2. 검색 유입 상위 10 키워드와 순위 변화
3. 글별 평균 체류 시간 (D.I.A. 대리 지표)
4. 이웃 수 증감, 댓글 응답률
5. 검수 통과율, 재생성 횟수 (파이프라인 품질)
6. 다음 주 키워드 제안

## 4. 리스크

| 리스크 | 확률 | 영향 | 대응 |
|--------|------|------|------|
| 저품질 판정 (검색 누락) | 중 | 높음 | 주제 일관성, 1일 1편, 외부 링크 제한, 사진 직접 촬영 |
| 애드포스트 반려 | 중 | 중 | 조건(90일·50편) 충족 후 신청, 반려 시 30일 후 재신청 |
| AI 생성 티로 신뢰 하락 | 중 | 높음 | 채점 임계값, 경험 문장, 사람 검토 |
| 에디터 자동화 실패 | 높음 | 낮음 | 클립보드 복사 모드 대체 |
| 사진 준비 부담으로 발행 중단 | 높음 | 높음 | 주말에 일주일치 캡처 일괄 준비, 사진 슬롯 3장으로 완화 옵션 |
